작전 통제 센터

초대코드 · 퀘스트 관리 · 개인 완료 체크 · Q&A

학생용 개발 명세서: 작전 통제 센터 (학교 퀘스트 보드)

1. 우리가 만들 것

AI 도구를 활용해서 만드는 일반 웹서비스다.

만들 서비스는 작전 통제 센터다.

같은 반 학생들이 수행평가·과제 마감 같은 일정(퀘스트)을 공유하고, Q&A로 묻고 답하며, 마감 임박순으로 모아 봐서 놓치지 않게 한다. 반을 만들면 초대코드가 생긴다. 친구들은 코드를 입력해 같은 반 보드에 들어온다.

2. 계층 구조

이 서비스의 핵심은 2단 계층이다.

학교 (school)
 └── 반 (class) — 4자리 초대코드로 참여
      ├── 퀘스트 (quest) — 제목·과목·마감일·설명
      │    └── Q&A — 질문·답변
      └── 완료 상태 — 개인별 localStorage, 공유 안 됨
  • 반 퀘스트: 같은 코드로 입장한 학생 전원이 공유한다.
  • 완료 체크: 퀘스트는 공유되지만, 내가 완료했는지는 나만 안다.
  • Q&A: 카테고리(퀘스트 관련·학교 생활·기타)로 분류해 질문·답변을 달 수 있다.

3. 서비스에 필요한 데이터

데이터설명예시
학교반이 속한 최상위 단위한빛고
반4자리 초대코드로 식별되는 그룹1학년 2반 / A3F7
퀘스트제목·과목·마감일·설명 포함국어 수행평가
Q&A질문·답변·닉네임·카테고리"분량 몇 장?" → "A4 2장"
완료 상태내가 끝낸 퀘스트 목록. 공유 안 됨quest id 배열

4. 기본 데이터 예시

const sessionData = {
  "A3F7KZ": {
    school: "한빛고", grade: "1", cls: "2",
    quests: [{ id: 1748500000000, title: "국어 수행평가", subject: "국어", due: "2026-06-05", desc: "A4 2장" }],
    qa:     [{ id: 1748500001000, nick: "초코", title: "분량 몇 장?", cat: "quest", answers: [{ nick: "라온", body: "A4 2장이요" }], open: true }]
  }
};
// 완료 상태는 브라우저마다 따로 저장
const myDone = new Set(JSON.parse(localStorage.getItem("done_A3F7KZ") ?? "[]"));

5. 만들어야 할 화면

메인 화면 — 작전 통제 센터

  • 신규 퀘스트 생성: 학교·학년·반 입력 → 4자리 초대코드를 직접 입력해 생성
  • 파티 입장: 코드 입력 → 불일치 시 오류, 일치 시 보드로 전환
  • 시스템 설정: 사격 파티클 · 야간 투시 ON/OFF

퀘스트 보드

  • 퀘스트 목록 탭: 등록 폼(제목·과목·마감일·설명) + 정렬 바 + 카드 목록(완료 체크·수정·삭제)
  • Q&A 탭: 질문 등록(닉네임·제목·내용·카테고리) + 답변 달기 + 펼치기·접기

6. 반드시 만들어야 하는 기능 (MVP)

아래 6개가 이 서비스의 MVP다.

FEATURE 01
반 만들기 / 참여
반을 만들면 4자리 초대코드가 생긴다. 친구는 코드를 입력해 같은 반 보드에 들어온다.
FEATURE 02
퀘스트 등록 / 수정 / 삭제
제목·과목·마감일·해야 하는 것을 입력해 등록한다. 수정은 모달, 삭제는 확인 후 제거한다.
FEATURE 03
마감일 D-day 표시 및 정렬
마감까지 남은 날을 색상으로 표시한다. 5가지 정렬 조건을 지원한다.
FEATURE 04
개인 완료 체크
내가 끝낸 퀘스트에 체크한다. 완료 상태는 나만 보이고 다른 친구에게는 공유되지 않는다.
FEATURE 05
Q&A
카테고리별로 질문을 올리고 답변을 단다. 답변은 펼치기·접기로 확인한다.
FEATURE 06
FPS 인터페이스
크로스헤어 커서, 클릭 파티클, 야간 투시. DungGeunMo 폰트 기반 픽셀 UI.

7. 앞으로 더 추가할 방향

지금은 기본 기능 위주지만, 다음 버전에서는 더 풍부한 분류와 학습 지원을 붙일 계획이다.

카테고리 분류
과제·수행평가·시험으로 퀘스트를 분류하고 필터링
학사 일정 연결
'해야 하는 것'과 '단순 일정'을 구분해 표시
Q&A 고도화
퀘스트에 Q&A를 직접 연결하거나 별도 게시판으로 분리
과목별 단어장
수행평가·시험 범위 개념을 과목별로 등록·공유
정렬 조건 확장
카테고리순, 완료 먼저 등 조건 추가
